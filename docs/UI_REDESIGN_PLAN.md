# Ad ID Warehouse UI/UX 完整迭代方案

> 状态：第一轮核心迭代完成
> 适用版本：v0.1
> 更新日期：2026-10-19
> 范围：广告位仓库、应用创建、广告位创建、流量分组与 eCPM、ID 配置，以及相关反馈和响应式体验

## 1. 背景与目标

当前产品已经具备应用管理、广告位管理、流量分组、ID 配置、Google Play 绑定、Excel 导入、JSON 备份及复制中心等完整能力。现有应用列表已经完成一轮信息层级、筛选、排序和批量操作优化，但创建流程仍依赖表格末尾草稿行，部分编辑操作使用浏览器原生 `prompt()`，创建应用、广告位和流量分组之间缺少连续引导。

本次迭代目标：

1. 建立统一、稳定、可复用的页面视觉层级。
2. 把“创建应用 → 创建广告位 → 配置初始流量分组和 eCPM”串成连续任务。
3. 降低表格内临时草稿、原生弹窗和隐式保存带来的理解成本。
4. 保留批量录入、键盘操作和高密度表格的效率优势。
5. 分别优化桌面端和移动端，不以简单缩放代替响应式设计。
6. 保持现有 JSON 数据层级、API、双模式持久化和历史数据兼容。

## 2. 设计原则

### 2.1 清晰优先

- 页面只保留一个最高强调的主操作。
- 关键字段始终显示标签，不只依赖 placeholder。
- 业务概念使用一致名称：统一称“参考 eCPM”，并明确其属于流量分组。
- 状态信息同时使用文字、颜色和图标，不只依赖颜色。

### 2.2 连续任务

- 创建完成后提供明确下一步，而不是让用户重新寻找入口。
- 用户已经输入的信息不得要求重复填写。
- 创建和编辑共用同一套表单、校验和视觉反馈。

### 2.3 高效操作

- 保留 `N`、`Enter`、`Esc`、`Ctrl/Cmd+K` 等现有快捷键。
- 常用操作直接可见，低频操作收纳到更多菜单。
- 批量操作继续围绕当前筛选结果和当前选中项工作。

### 2.4 风险可控

- 删除、覆盖导入、批量生成等操作展示影响范围。
- 保存失败时保留用户输入，并提供重试。
- 不因 UI 改版改变数据模型和业务计算口径。

## 3. 数据与业务约束

### 3.1 保持现有层级

```text
Application
└── Format
    └── Placement
        └── Segment（参考 eCPM 位于此层）
            └── ID Config
```

创建广告位时填写的 eCPM 将用于同步创建“初始流量分组”，不会把 eCPM 新增到 `Placement`。

### 3.2 新底价倍率

本次迭代统一采用以下倍率：

| 组标识 | 计算公式 |
| --- | --- |
| L | `参考 eCPM × 1.35` |
| H | `参考 eCPM × 1.55` |
| M | `参考 eCPM × 1.85` |

倍率必须同步用于：

- 页面实时预览。
- `app.js` 中锁定 ID 的底价重算。
- `importer.js` 中 Excel 导入预览和差异校验。
- README、AGENTS.md 和用户帮助文案。

### 3.3 新建广告位的可选项

新建广告位不使用下拉框或原生单选圆点，使用平铺标签按钮。

广告类型：

| 显示标签 | 内部 key | 业务名称 |
| --- | --- | --- |
| Inter | `interstitial` | 插屏 |
| Navite | `native` | 原生 |
| Open | `appopen` | 开屏 |

聚合平台：

| 显示标签 | 保存值 |
| --- | --- |
| Admob | `Admob` |
| TradPlus | `TradPlus` |
| Topon | `Topon` |

说明：标签文案 `Navite` 按当前需求保留，内部仍映射到 `native`。新建入口只展示以上三种类型；历史 Rewarded、Banner 等数据继续正常显示、编辑、导入和导出，不执行数据迁移或删除。

## 4. 页面信息架构

### 4.1 全局框架

桌面端继续采用左侧导航和右侧工作区：

- 左侧：品牌、广告位仓库、复制中心、主题和同步状态。
- 顶部第一层：面包屑切换器、状态胶囊、全局搜索。
- 页面第二层：页面标题、统计、主操作和次级工具。
- 主内容：筛选栏、批量工具栏、数据表格或流量分组手风琴。

顶部区域保持 sticky，但不得遮挡键盘焦点和错误提示。

### 4.2 页面层级

```text
应用仓库
├── 应用列表
├── 创建/编辑应用面板
└── 应用详情
    ├── 广告位列表
    ├── 创建/编辑广告位面板
    └── 广告位详情

```

## 5. 视觉系统

### 5.1 颜色

沿用现有蓝色主色，橙色仅用于警告和待处理状态，绿色用于成功和完整状态。

| Token | 浅色模式建议值 | 用途 |
| --- | --- | --- |
| `--bg` | `#F5F7FB` | 页面背景 |
| `--panel` | `#FFFFFF` | 卡片、抽屉、表格 |
| `--panel-soft` | `#F8FAFC` | 表头、筛选背景 |
| `--text` | `#17233B` | 主文字 |
| `--muted` | `#65748B` | 次级文字 |
| `--line` | `#E4EAF2` | 边框与分隔线 |
| `--brand` | `#315CF5` | 主操作和焦点 |
| `--green` | `#16A34A` | 成功、完整 |
| `--orange` | `#D97706` | 待处理、警告 |
| `--danger` | `#DC2626` | 删除和错误 |

深色模式保持相同语义，颜色对比度满足正文 4.5:1、组件边界和焦点环 3:1。

### 5.2 字体与层级

| 元素 | 规格 |
| --- | --- |
| 页面标题 | 18–20px / 700 |
| 区块标题 | 15–16px / 700 |
| 表格正文 | 13px / 400–600 |
| 辅助信息 | 11–12px / 400–600 |
| 数值、ID、包名 | 等宽字体，启用 tabular numbers |

### 5.3 间距与尺寸

- 使用 `4 / 8 / 12 / 16 / 24 / 32px` 间距序列。
- 桌面按钮高度：34–38px。
- 移动端按钮和可点击标签高度：至少 44px。
- 输入框高度：桌面 40px，移动端 44px。
- 卡片圆角：12px；按钮圆角：8px；标签圆角：8px 或胶囊形。
- 抽屉宽度：桌面 440–480px，最大不超过视口宽度的 45%。

### 5.4 动效

- 抽屉进入：180–220ms，位移配合透明度。
- 标签切换、按钮反馈和状态变化：120–180ms。
- 表格新建行成功后使用一次 600–900ms 的浅色高亮。
- 动效只使用 `transform` 和 `opacity` 等低成本属性。
- `prefers-reduced-motion: reduce` 下关闭非必要动效。

## 6. 应用仓库页面

### 6.1 页面头部

左侧：

- 标题“应用仓库”。
- 当前筛选结果数量和数据模式说明。

中部统计：

- 应用总数。
- 配置完整。
- 待处理。

右侧操作：

- 主按钮：`＋ 创建应用`。
- 次级按钮：导入 Excel、导入备份、导出备份。
- 窄屏时将三个次级按钮收纳为“导入/导出”菜单。

### 6.2 搜索与筛选

- 搜索范围：应用名称、商店名称、包名、开发者、分类。
- 配置状态：全部、配置完整、待检查、未配置。
- 广告类型、广告位数量、排序继续使用现有组合筛选。
- 当前筛选条件使用可关闭标签显示。
- 无结果时区分“仓库为空”和“筛选无结果”，后者提供“清除条件”。

### 6.3 应用行

应用行按以下优先级展示：

1. 图标或字母占位。
2. 应用代号。
3. 商店真实名称。
4. 包名、开发者和分类。
5. 广告类型、广告位数量和 ID 完成状态。

交互规则：

- 点击非操作区域进入应用详情。
- Hover、`focus-within` 和触屏模式均可访问行操作。
- 常用操作：编辑、绑定/刷新 Play 信息、复制应用名。
- 删除收纳到危险操作，使用明确文字确认影响。
- 批量选择后显示 sticky 批量栏，筛选变化时只保留可见选中项。

## 7. 创建与编辑应用

### 7.1 展现方式

- 桌面端：右侧抽屉。
- 移动端：全屏面板。
- 创建和编辑复用同一组件。
- 打开后焦点进入第一个字段；关闭后焦点返回触发按钮。
- 有未保存输入时关闭，显示面板内确认，不使用浏览器原生 confirm。

### 7.2 表单字段

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| 应用名称/代号 | 是 | 去除首尾空格；检查重复和文件名非法字符 |
| Google Play 包名或链接 | 否 | 接受包名或完整 Play 链接；显示解析后的包名 |

开发模式下，包名失焦或按 Enter 后抓取商店预览：图标、标题、开发者和分类。静态模式不请求接口，显示“静态模式暂不支持商店抓取，可先创建后在开发模式绑定”。

### 7.3 操作

- 主按钮：`创建并配置广告位`。
- 次按钮：`创建并继续添加`。
- 编辑模式主按钮：`保存修改`。
- 取消：关闭面板；没有修改时直接关闭。
- `Ctrl/Cmd+Enter` 提交，`Esc` 关闭。

### 7.4 校验与反馈

- 空名称、重复名称和非法文件名字符在字段下方就地提示。
- 提交期间按钮显示 loading 并禁用重复提交。
- 保存成功后关闭或重置面板，新建行高亮，Toast 作为补充反馈。
- 保存失败时保留全部输入，在面板底部显示错误和“重试”。

## 8. 广告位列表

### 8.1 页面头部

- 标题显示当前应用名称和广告位数量。
- 主按钮：`＋ 创建广告位`。
- 显示广告位总数、流量分组总数和待回填 ID 数量。

### 8.2 广告位行

字段：广告位代码、类型、平台、流量分组、ID 完成度和操作。

交互：

- 点击行进入广告位详情。
- 类型和平台使用只读标签，颜色语义稳定。
- ID 完成度同时显示数字和进度条。
- 编辑使用与创建相同的侧边面板，不再使用多个 `prompt()`。
- 删除确认必须显示广告位名称、流量分组数和将删除的 ID 数。

## 9. 创建与编辑广告位

### 9.1 面板结构

面板分为两个区块：

1. 广告位信息。
2. 初始流量分组。

顶部显示当前所属应用，避免用户在跨层级操作时失去上下文。

### 9.2 广告位信息

#### 广告位代码

- 必填。
- 同一应用内检查重复。
- 显示命名示例，但不擅自改写用户输入。

#### 广告类型标签

直接平铺三个按钮：

```text
[ Inter ] [ Navite ] [ Open ]
```

- 默认：`Inter`。
- 单击切换，选中项使用主色背景、勾选图标和更高对比度。
- 使用原生 `button` 和 `aria-pressed`，不渲染 radio 圆点。
- 左右方向键移动选择，Space/Enter 确认。

#### 聚合平台标签

```text
[ Admob ] [ TradPlus ] [ Topon ]
```

- 默认：`Admob`。
- 交互与类型标签一致。

### 9.3 初始流量分组

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| 分组名称 | 是 | 保留中文和内部空格；首尾空格清理 |
| 参考 eCPM | 是 | 数字，最小 0，步进 0.5；允许合法的 0 |

说明文案：“参考 eCPM 属于首个流量分组，用于计算 L/H/M 底价。”

输入 eCPM 后实时展示：

```text
L  $27.00   = $20.00 × 1.35
H  $31.00   = $20.00 × 1.55
M  $37.00   = $20.00 × 1.85
```

预览值保留最多两位小数，使用项目现有舍入规则。输入为空或非法时显示占位，不使用默认值覆盖用户输入。

### 9.4 提交行为

- 主按钮：`创建并进入 ID 配置`。
- 次按钮：`创建并返回列表`。
- 一次创建 `Format`、`Placement` 和初始 `Segment`，然后统一保存应用。
- 任一步校验失败均不写入部分数据。
- 创建成功后进入新广告位，并展开初始流量分组。

### 9.5 编辑行为

- 编辑广告位可修改代码、类型和平台。
- 初始面板不直接批量改写所有流量分组 eCPM。
- eCPM 在流量分组行或“编辑流量分组”面板中修改。
- 修改类型时复用已有 Format；空 Format 是否清理由实现阶段单独验证，避免遗留孤立结构。

## 10. 流量分组与 eCPM

### 10.1 手风琴行

每行展示：

- 展开状态。
- 优先级 P1、P2……
- 分组名称。
- ID 完成状态。
- 参考 eCPM。
- 编辑、删除和展开操作。

整行可展开，但输入框、按钮和菜单必须阻止行导航事件。

### 10.2 eCPM 行内编辑

- 输入框前固定 `$`，使用等宽数字字体。
- 聚焦时显示当前 L/H/M 计算预览。
- 输入合法数字后进入“待保存”，1 秒防抖后保存。
- 保存状态：待保存、保存中、已保存、保存失败。
- 空值、负数、非数字不触发保存，并显示字段级错误。
- 输入 `0` 必须保存为 0，不得通过 `|| 20` 回退为 20。
- 保存失败保留输入，提供重试。

### 10.3 新建与编辑分组

- 使用轻量面板或手风琴内完整表单，不再使用 `prompt()`。
- 字段：分组名称、优先级、参考 eCPM。
- eCPM 下方实时显示新倍率预览。
- 新建成功后自动展开该分组并聚焦 ID 配置区。

## 11. ID 配置矩阵

### 11.1 信息结构

继续保留高密度表格：序号、广告源、组标识、底价、广告名称、广告 ID、Meta ID、联动和操作。

优化点：

- sticky 表头与首列，横向滚动时保留上下文。
- L/H/M 分段使用轻量背景和左侧分隔，不使用大面积强色。
- 自动计算字段呈只读样式，并展示计算来源提示。
- 空 ID 使用明显但克制的“待回填”状态。

### 11.2 单行操作

- H/L/M 标签切换后实时重算底价和广告名称。
- 锁定按钮使用文字 Tooltip 解释联动含义。
- 删除按钮只在 Hover、focus 或触屏操作区显示，但必须可通过键盘到达。
- 保存状态附着在当前行，避免只在页面底部显示。

### 11.3 批量生成

- 面板内显示每组数量、总生成数量和覆盖影响。
- 覆盖前展示“现有 N 条将被替换”。
- 数量限制 1–50，每次生成总量为 `3n`。
- 平台默认沿用广告位所选平台；如业务仍要求固定 Admob，需要在实施前统一业务口径。
- 成功后显示生成数量并聚焦第一条待回填广告 ID。

### 11.4 复制与粘贴

- 列复制、极速粘贴和可视化粘贴继续保留。
- 所有复制反馈使用按钮局部成功态加 Toast。
- 粘贴预览明确显示目标列、输入行数、可填槽位和覆盖数量。
- 覆盖已有 ID 时使用警告色，不静默覆盖。

## 12. Google Play 绑定

- 创建应用时可选填包名，后续仍可独立绑定或更改。
- 抓取中显示骨架和明确加载文案。
- 找不到应用与网络失败分为不同状态。
- 图标加载失败降级为字母徽章，不改变行高。
- 静态模式解释限制，并引导通过开发模式刷新商店数据。
- 外链按钮带可访问名称，并明确会打开 Google Play。

## 13. 导入、导出和备份

### 13.1 Excel 导入

- 文件选择后显示解析进度。
- 预览顶部显示应用、广告位、流量分组和 ID 数量。
- 类型无法识别时，选择控件与新建广告位使用一致的标签视觉；导入仍兼容历史类型。
- 底价差异使用新倍率计算。
- 导入按钮显示最终影响数量。

### 13.2 JSON 导入

- 区分整库覆盖和单应用合并。
- 覆盖确认展示当前应用数与待导入应用数。
- 失败文件逐项列出原因，不只显示短暂 Toast。

### 13.3 导出

- 全库导出、筛选应用导出和单应用导出使用一致文案。
- 成功反馈显示导出数量和文件名。
- 静态模式提示备份的重要性，但不重复打扰用户。

## 14. 删除与危险操作

危险操作分三级：

| 等级 | 操作 | 交互 |
| --- | --- | --- |
| 低 | 删除空 ID 槽位 | 行内确认或短确认 |
| 中 | 删除流量分组 | 展示 ID 数量和分组名 |
| 高 | 删除广告位、应用、覆盖整库 | 专用确认面板，展示影响范围 |

确认按钮使用具体动词，例如“删除 1 个广告位和 27 条 ID”，避免使用含糊的“确定”。

## 15. 反馈与状态系统

### 15.1 反馈层级

1. 字段级：校验错误、帮助文字。
2. 组件级：按钮 loading、行保存状态、复制成功。
3. 页面级：导入结果、保存失败、模式限制。
4. Toast：作为短暂补充，不承载必须阅读的信息。

### 15.2 状态文案

统一使用：

- `待保存`
- `保存中…`
- `已保存`
- `保存失败 · 重试`
- `已复制 N 项`
- `已创建并进入配置`

同一操作进行中时禁用重复提交，但允许取消不影响数据的浮层。

## 16. 键盘和焦点

| 按键 | 行为 |
| --- | --- |
| `Ctrl/Cmd+K` | 聚焦当前视图搜索 |
| `N` | 打开当前层级的新建面板 |
| `Ctrl/Cmd+Enter` | 提交创建/编辑表单或批量粘贴 |
| `Esc` | 关闭最上层浮层；有未保存输入时提示 |
| `↑ / ↓` | 列表和下拉项目导航 |
| `← / →` | 类型、平台等标签组选项切换 |
| `Tab / Shift+Tab` | 按视觉顺序移动焦点 |

打开抽屉或模态框后焦点限制在其内部；关闭后返回触发元素。所有只在 Hover 出现的操作在 `focus-within` 时也必须出现。

## 17. 响应式设计

### 17.1 桌面端（> 1200px）

- 完整侧栏、统计、筛选和表格列。
- 创建面板从右侧进入，不遮挡整个列表。
- 表格维持高信息密度。

### 17.2 中等宽度（769–1200px）

- 统计区缩小，次级操作进入菜单。
- 非关键表格列允许收纳或横向滚动。
- 抽屉宽度不超过视口 50%。

### 17.3 移动端（≤ 768px）

- 侧栏切换为底部导航或紧凑菜单。
- 应用和广告位列表改为卡片行，不强行压缩六列表格。
- 创建和编辑使用全屏面板。
- 标签组自动换行，每项高度至少 44px。
- 底部操作区 sticky，并处理安全区域 `env(safe-area-inset-bottom)`。
- ID 矩阵保留横向滚动，首列和表头 sticky。

## 18. 可访问性

- 使用原生 `button`、`input`、`label` 和表格语义。
- 类型和平台标签使用 `aria-pressed` 或合适的单选组语义，但视觉上不出现 radio 圆点。
- 输入错误通过 `aria-describedby` 关联到错误文字。
- 模态框和抽屉具有标题、可访问名称和焦点管理。
- 所有图标按钮提供 `aria-label`。
- 正文对比度至少 4.5:1，组件边界和焦点环至少 3:1。
- 桌面最小点击目标 24×24px，主要操作与移动端目标至少 44×44px。
- 支持 `prefers-reduced-motion`。

## 19. 前端状态建议

新增统一面板状态，替代应用、广告位和分组创建时散落的草稿行：

```js
state.editor = {
  type: null,            // app | placement | segment
  mode: 'create',        // create | edit
  values: {},
  errors: {},
  dirty: false,
  submitting: false,
  returnFocus: null
}
```

广告位创建建议值：

```js
{
  code: '',
  adType: 'interstitial',
  mediation: 'Admob',
  segmentName: '',
  eCPM: '20'
}
```

输入阶段保留字符串值，提交校验通过后再转为数字，避免空值和 `0` 被错误回退。

## 22. 验收用例

### 22.1 创建应用

- 空名称不能提交，错误与字段关联。
- 重复名称不能覆盖已有应用。
- 非法文件名字符被明确拦截。
- 创建成功后可直接进入广告位创建。
- 静态模式创建后数据写入 localStorage。

### 22.2 创建广告位

- 默认选中 Inter 和 Admob。
- 标签可通过鼠标、触屏和键盘切换。
- 同一应用重复广告位代码被拦截。
- eCPM `0`、`0.5`、`20` 均按原值保存。
- 负数、空值、非数字不能提交。
- eCPM 为 20 时预览为 L=27、H=31、M=37。
- 创建结果包含一个 Placement 和一个初始 Segment。

### 22.3 倍率与导入

- 页面、重算和 Excel 预览都使用 1.35/1.55/1.85。
- 组标识切换后底价和广告名称同步更新。
- 历史数据加载后按锁定规则处理，不破坏 ID 字段。

### 22.4 保存与错误

- 自动保存过程中显示状态。
- 保存失败时输入仍存在。
- 快速重复点击不会创建重复对象。
- 离开未保存面板时得到明确提示。

### 22.5 响应式和可访问性

- 360px 宽度下表单可完整操作。
- 移动端标签点击目标不小于 44px。
- 抽屉内 Tab 不会跳到页面背后。
- Esc 只关闭最上层浮层。
- 明暗主题文字、边框和焦点可辨识。

## 23. 风险与处理

| 风险 | 处理方式 |
| --- | --- |
| 新建类型缩减影响历史数据 | 只限制新建入口，保留历史显示、导入和保存兼容 |
| 广告位创建同时写入多层对象 | 提交前完整校验，构造完成后一次写入和保存 |
| eCPM 字符串/数字转换导致 0 丢失 | 输入阶段保存字符串，显式使用 `Number.isFinite` 校验 |
| 抽屉与全量 render 冲突 | 将 editor 状态纳入集中 state，并恢复焦点 |
| 移动端高密度矩阵难以阅读 | 保留横向滚动、sticky 上下文，并把批量操作放到固定工具区 |
| 文档与实现再次漂移 | 每个阶段同时更新 README、AGENTS.md 和本计划状态 |
